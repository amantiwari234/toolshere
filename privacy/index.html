Verified In-Browser File Processing Architecture

ToolsHere is engineered around client-side execution. When using our file-based tools—including Image Compressor, Image Converter, Background Remover, Merge PDF, and Compress PDF—your files are processed directly inside your browser's local memory.

Client-Side Web APIs: Tools operate via standard browser APIs, including HTML5 Canvas 2D context manipulation, the JavaScript FileReader API, and in-memory WebAssembly/JavaScript libraries.
Zero Server File Transmission: Selected files are never uploaded to, transmitted across, or stored on ToolsHere.online backend servers. We do not operate remote file storage databases.
Memory Volatility: Document and image data reside only in transient browser memory and are discarded when you refresh or close the browser tab.

User Responsibility Notice: Because processing occurs exclusively on your local device without cloud backup, you remain responsible for maintaining backups of your original documents and images before manipulation.

First-Party Local Storage & Tracking Hygiene

ToolsHere maintains clean first-party storage hygiene. Our proprietary scripts do not write or read first-party cookies (document.cookie is never accessed by custom site code). We use browser localStorage solely for functional UI preferences:

  • theme: Stores your visual display preference (light or dark).
  • th_favorites: Stores a local array of your favorited tool identifiers to pin them to the top of your dashboard.

No Device Fingerprinting: Aligned with our advertising setup, Special Feature 2 is disabled. ToolsHere does not perform canvas fingerprinting, scan device characteristics, or track hardware configurations to identify individual users.

Third-Party Services, CDNs & External Requests

While document manipulation occurs strictly in your browser, loading certain pages and utility features makes external network calls:

  • YouTube Thumbnail Grabber: When entering a YouTube URL, our script queries public thumbnail endpoints (img.youtube.com) routed through the public caching proxy images.weserv.nl to bypass browser Cross-Origin Resource Sharing (CORS) restrictions. Only the public video identifier is transmitted.
  • Dynamic Open-Source Libraries: To ensure fast page loads, specific utilities load static open-source scripts on-demand from Cloudflare's CDN (cdnjs.cloudflare.com), including PDF.js for PDF to Word Text Extractor and QRCode.js for QR Code Studio. Core PDF utilities (Merge, Compress, Image to PDF) use pdf-lib.min.js hosted locally on our own domain.
  • Web Fonts & Icons: Tools pages load FontAwesome icons from cdnjs.cloudflare.com, and 404 pages utilize Inter font assets from Google Fonts (fonts.googleapis.com).
